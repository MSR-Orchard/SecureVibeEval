# SusVibes guardrail assets

`prompts.py`, `cwes.yaml`, and `get_guardrail` in `tools.py` provide the CLI
harness's generic, self-selection, oracle, feedback-driven, and sec-test modes.
`tools.py` also provides grading-statistics helpers.

CWE descriptions supply context for self-selection and oracle prompts.
See the [harness guide](../../../../harness/README.md) for strategy inputs
and configuration.
